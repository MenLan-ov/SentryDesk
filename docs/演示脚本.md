# 5 分钟演示脚本与答辩要点

> 目标：让评委在 5 分钟内看到「离线可用 → 有真实数据 → 能学能练 → 有闭环 → 工程可信」。
> 全程**断网演示**是本作品最强的差异化动作，务必开场就说明。

---

## 零、演示前检查（30 秒）

| 检查 | 命令/动作 |
|---|---|
| 已安装 | 开始菜单搜 `SentryDesk` |
| 情报有数据 | 打开后点「情报」，左上角应显示 2900+ 条 |
| 学习数据干净 | 设置 → 数据 → 「清空学习进度」（可选，让演示从零开始） |
| 断网 | 关闭 Wi-Fi / 拔网线 |
| 字号 | 答辩投影建议设置 → 外观 → 字号「大」 |

> 若评委要求看「首装状态」：设置 → 数据 → 清空并退出，再打开，可现场看一次种子导入
> （日志：`%APPDATA%\com.sentrydesk.app\sentrydesk.log`，含 `种子情报库导入 2979 条`）。

---

## 一、开场（0:00–0:30）

**说**：

> 这是一个离线优先的漏洞知识库与安全学习工作台。
> 它把 CISA KEV、NVD 这类公开情报，变成能学、能测、能复习的知识资产。
> 现在我把网断掉，接下来所有操作都在断网状态下完成。

**做**：点右上角主题按钮切到「护眼」，再切回，展示界面跟得上（可选，10 秒）。

---

## 二、情报 → 教学卡（0:30–1:40）

**做**：

1. 点「情报」页 → 说明左上角是 **2979 条**、随安装包分发
2. 搜索框输入 `CVE-2024`（或任一点开）
3. 点开一条 → 右侧详情显示：描述、CVSS、CWE、**信息来源与许可**
4. 点 CWE 标签 → 直接跳到对应教学卡

**说**：

> 情报不是死的列表。每条漏洞都关联到 CWE 弱点，点一下就跳到对应的教学卡——
> 这是「从一条新闻到一次学习」的路径。数据来源和许可在详情里有标注，采集遵守 robots 与限速。

**加分动作**：详情页底部「接着学」列出 3 张相关卡，说明这是知识图谱式的关联，不是简单标签。

---

## 三、教学卡 + 自测 + 错题（1:40–3:10）

**做**：

1. 打开一张卡（建议「SQL 注入」或「SSRF」）→ 展示中英双语、代码块 bad/good 对照
2. 底部「自测」→ 做 2 题，**故意答错 1 题**
3. 点「错题」→ 看到的不是死列表，而是「待复习 · 10 分钟后」
4. 点「开始复习」→ 三档按钮（忘记 / 有点印象 / 记住了）→ 选「记住了」

**说**：

> 答错不是终点。错题进入间隔重复队列：忘记的 10 分钟后再问，记住的间隔从 1 天、
> 6 天逐步拉长，ease 系数会随表现调整。这是 SM-2 的简化实现，排期算法有独立单测。

---

## 四、看板与学习路径（3:10–4:00）

**做**：

1. 点「看板」→ 首排 5 项：已掌握、自测均分、笔记、连续天数、待复习
2. 点「路径」→ 展示 14 条岗位视角路径，任选一条（推荐「红蓝对抗（ATT&CK 视角）」）
3. 点「导出报告」→ 生成一张 PNG

**说**：

> 看板不是数据看板，是**学习看板**：连续学习天数、待复习量这些才是驱动因素。
> 14 条路径按岗位组织——应用安全、供应链、云原生、红蓝对抗，每条都是「按顺序学什么」。
> 这张 PNG 可以贴进周报或答辩材料。

---

## 五、工程质量（4:00–4:45）

**做**（三选二，看时间）：

1. `Ctrl+K` 打开命令面板 → 输入「ssrf」→ 回车直达
2. 按 `?` 打开快捷键总览
3. 设置 → 关于：版本、内容规模、数据来源、许可、检查更新

**说**：

> 全部本地：SQLite + FTS5 全文检索，无账号、无遥测、不上传任何数据。
> Rust 6200 行 + 前端 8000 行，40 个单元测试，CI 三作业。
> 安装包有 Authenticode 与 minisign 两套签名，装完可选目录、可离线升级。

---

## 六、收尾（4:45–5:00）

**说**：

> 一句话总结：**把公网情报变成可教学、可自测、可复习的知识资产，全程不联网。**
> 它解决的是「看得懂漏洞，但记不住原理」这个问题——情报是入口，教学卡是方法，
> 间隔重复是保证记住的手段。

## 七、预判提问与回答

| 评委可能问 | 回答要点 |
|---|---|
| 数据从哪来？会不会侵权？ | CISA KEV（美国 CISA 公开发布）、NVD（NIST，公有领域）、GHSA（CC-BY-4.0）；每张卡 `refs` 字段标注来源，`docs/数据来源与合规.md` 有完整清单与许可 |
| 情报会不会过期？ | 随包是快照（页面上标注时点），设置页可在线刷新（robots 校验 + 限速 + 固定 UA）；离线也保证有基线数据可演示 |
| 和 XX 漏洞库/学习平台有什么区别？ | 那类产品是「查」，本作品是「学完记住」：情报→CWE→卡→自测→间隔重复→路径，闭环在本机完成，无需账号 |
| 为什么用 Tauri 不用 Electron？ | 安装包 4 MB vs 80 MB+，内存占用低一个量级；Rust 侧可做 FTS5 检索与数据库自恢复，安全边界更小 |
| 内容是你写的吗？ | 110 张卡全部原创撰写，参考来源逐卡标注；中英双语 100% 覆盖（脚本可当场核验 `_tools/i18n_status.py`） |
| 数据库坏了怎么办？ | 打开时完整性校验，损坏自动备份为 `.corrupt-<时间戳>` 并重建，不弹错误框 |
| 更新怎么保证安全？ | minisign 签名校验（公钥内置），签名不匹配拒绝安装；安装包另有 Authenticode 签名 |
| 只有 Windows？ | 当前只出 Windows 安装包；Tauri 代码本身跨平台，macOS/Linux 需补打包与测试（不吹未验证的能力） |

## 八、演示禁区（别做）

- ❌ 不要现场演示「检查更新」——除非已发布 Release 且仓库为 Public
- ❌ 不要现场清空数据库后等采集完成——采集依赖网络，且受源站限速
- ❌ 不要打开开发者工具或终端讲代码结构，5 分钟不够，讲数据流即可
- ❌ 不要承诺未实现的功能（移动端、多人协作、云同步）
