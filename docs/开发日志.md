## v1.0.5 · 参赛版与上线

**主题：以「可现场演示」为验收标准做全量收口，并从本地项目变成公开仓库。**

### 新增

- **种子情报库**：`knowledge/seed/` 随包分发 CISA KEV 快照（1779 条）+ 近 30 天 CVE（1200 条）。
  首启若情报表为空则自动导入（实测 2979 条），全程离线；导入幂等，重复启动不会重复写入（有单测覆盖）
- **首次启动引导**：三步向导（选语言 → 认识内容 → 现场做一道题），可跳过，本地记忆
- **学习报告导出**：一键生成一页式 PNG（指标卡 + 分类掌握条），可直接放进答辩材料
- **检查更新**：接入 `tauri-plugin-updater`（minisign 签名 + `.sig` 产物），失败静默降级
- **学习指标**：看板首排展示连续学习天数、待复习错题等 5 项
- **状态栏数据时点**：显示「数据截至 YYYY-MM-DD」，让评委明白快照不是死数据

### 变更

- 安装向导**恢复目录选择页**（v0.8.6 曾移除，事后证明是误判）：默认仍为当前用户目录，
  升级沿用上次的安装位置；被动/更新模式自动跳过；选到不可写位置自动改道推荐目录
- 详情页补「接着学」3 张相关卡 + 同 CWE 情报一键跳转，闭合「情报 → 教学」链路
- 学习路径 10 → 14 条：新增红蓝对抗（ATT&CK）、供应链、云原生、代码评审视角
- 关于页重写：版本号常量单一来源、内容规模、数据来源与许可、第三方组件、反馈入口
- 字号三档（标准/大/特大）；浅色与护眼主题正文对比度提升到 WCAG AA
- 版本号去掉 Beta 后缀

### 内容

- 教学卡 107 → 110 张：补齐 CWE-444（HTTP 请求走私）、CWE-119（缓冲区越界）、CWE-772（资源未释放），
  CWE Top 25 全覆盖且每张含 bad/good 最小复现
- 自测题 329 → 338 道；中英双语覆盖率 100%（题目 242/242、正文 339/339）

### 修复

- **安装失败的四年误诊终结**：真因是安全软件按进程拦截未提权安装器落地 exe
  （v0.8.4~v0.8.6 的「占用自愈」「目录改道」「错误码保险」均为阶段性误判）。
  最终方案：启动即申请管理员 + Authenticode 代码签名 + 用最终文件名真实写入探测 + 旧 exe 改名让位
- 加回目录页后引入的回归：上游模板相对占位路径导致静默安装跑到桌面，
  改为绝对默认路径 + `.onInit` 判断同步修正
- 并发写压测偶发 `database is locked`：测试用了 deferred 事务（锁升级时 busy_timeout 不生效），
  改用与产品写路径一致的 `BEGIN IMMEDIATE`；用「双套件并行」实验完成复现→修复→验证闭环
- 桌面残留的单文件旧版导致版本漂移（旧 exe 内嵌旧内容，永远显示 v0.7.6），
  确立发布纪律：只发 `setup.exe` 与 `portable.zip`，不投放裸 exe

### 工程与上线

- CI 三作业：前端类型检查 + 构建、Rust 测试 + clippy、内容一致性校验（`_tools/ci/check_knowledge.py`）
- README 全量重写；补 LICENSE（MIT）、`docs/数据来源与合规.md`、`docs/发布与更新.md`、
  `docs/演示脚本.md`、7 张当前版本中文截图；评审文档追加实测复评章节
- 仓库推送至 GitHub 并转为 Public；发布 Release v1.0.5（安装包 / 签名 / 便携版 / latest.json 四资产），
  应用内自动更新链路实测可匿名拉取；仓库 About 区补描述与 12 个主题标签
- 便携版打包改用 Python `zipfile`（写 UTF-8 标志位），修复中文文件名乱码
- 开发收尾：四份报告归档 `docs/reports/`，安装器模板与品牌图生成脚本收编 `_tools/pack/`
- Rust 单测 40 个全过，`vue-tsc` 零错误，CI 全绿

## v0.8.7 · 安装器真因修复

**主题：三次安装失败的根因终于定位——不是占用、不是目录，是杀软拦进程。**

### 修复

- 用户发现「以管理员身份运行就能装」，顺此确认真因：安全软件按进程拦截**未提权**安装器写 exe
- 安装器 `RequestExecutionLevel admin`，启动即 UAC；自签名证书签名主程序与安装包
- 写入探测改用**最终文件名**真实写 1 字节（杀软拦 `.exe` 不拦 `.tmp`，旧探测给出假阴性）
- 升级时先把运行中的旧 exe 改名为 `.old` 让位，取消安装则还原
- 诊断日志 `%TEMP%\SentryDesk-setup.log`，单句柄三级路径回退

## v0.8.4 · 安装器占用自愈

**主题：安装报「无法写入」的第一轮修复，先解决「程序在跑」这一类。**

### 修复

- 安装时若程序正在运行，先结束进程再写入；失败给出可操作提示而非系统裸错误框
- 补齐缺失的 `installerHooks` 配置——此前钩子从未进过安装包，是「无法写入」的第一层原因
